How does this work? (Plain-English Guide)

1. Pick a goal: Choose one of the 4 cards below, or paste a path to your own text/code folder and click Train My Data.

2. Automatic training: Helix builds a small frozen Base Trunk, then grows modular DNA Strands (.sp patches) on top without overwriting the base — every file is SHA-256 verified.

3. Try it immediately: When training finishes, click Try Your Model → to chat/generate with standard text, OMG-Masked (100% compiler-valid code), or Arboris-Guided (fast associative bypass).

Glossary: Base Trunk = frozen foundation model · DNA Strand (.sp) = portable skill patch · spclip = blends strands at runtime · OMG-Masked = grammar wall guaranteeing valid .om code · Arboris-Guided = skips neural layers on known patterns.
